## How to run it

The image is already finished — `main.py` copies it to the output folder
and checks it is a valid PNG within the size and dimension limits:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

That writes `out/entry.png`. Standard library only, no network.
